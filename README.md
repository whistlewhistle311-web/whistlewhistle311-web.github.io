# Free budget calculators and money guides

Small, free tools that run in the browser. Nothing you type is stored or sent anywhere.

## Calculators (English)
- [50/30/20 budget calculator](https://whistlewhistle311-web.github.io/tools/50-30-20/) — counts BNPL and installment payments as needs
- [Paycheck budget calculator](https://whistlewhistle311-web.github.io/tools/paycheck-budget/) — weekly, biweekly, semi-monthly or monthly pay; assigns each bill to a paycheck
- [Debt payoff calculator](https://whistlewhistle311-web.github.io/tools/debt-payoff/) — snowball vs avalanche, month by month
- [Sinking funds calculator](https://whistlewhistle311-web.github.io/tools/sinking-funds/)
- [Holiday budget calculator](https://whistlewhistle311-web.github.io/tools/holiday-budget/)
- [Wedding budget calculator](https://whistlewhistle311-web.github.io/tools/wedding-budget/)
- [All tools](https://whistlewhistle311-web.github.io/tools/)
