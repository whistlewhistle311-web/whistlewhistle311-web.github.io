Contact

Found a number that looks wrong, a rule that changed, or have a request for a calculator? Tell us and we will check it against the official source and fix it.

  • Report an error or request a calculator: open an issue (a free GitHub account is needed).
  • Questions about a paid template: use the contact button on our Gumroad store.

Please include the page address, the numbers you entered and what you expected. We usually reply within a few days.
