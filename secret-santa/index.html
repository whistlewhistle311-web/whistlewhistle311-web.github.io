Secret Santa generator with a private link for each person

Doing Monito Monita or Kris Kringle at the office or with barkada? Same thing: everyone gets a private link showing only their monito or monita. Send each link by Messenger or Viber.

Type everyone's name, add couples who should not draw each other, and press draw. You get one link per person. Each link shows only who that person buys for. The draw runs in your browser and nothing is stored on a server.

How to run it

  1. Type the names and any pairs who should not get each other, like partners or people who live together.
  2. Press Draw names. Copy each person's link and send it to them privately (text, chat or email).
  3. Everyone opens their own link and sees only their match, the budget and the date.

If you are organizing and playing too, send the links without opening the others. Draw again any time to reshuffle; old links keep showing the old draw, so send the new ones.
