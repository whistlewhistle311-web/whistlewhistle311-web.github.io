Como sair das dívidas: um plano em 5 passos, com números

Sair das dívidas quase nunca depende de um truque. Depende de ter todas as dívidas numa lista, pagar sempre os mínimos e mandar um valor extra fixo para uma dívida de cada vez. Aqui está o plano e um exemplo completo para ver quanto muda.

Os 5 passos

  1. Faça a lista. Cada dívida com saldo, juros ao mês (como aparece na fatura e no contrato) e pagamento mínimo. Cartão, cheque especial, empréstimo, financiamento, o que você deve para a família.
  2. Pague todos os mínimos. Deixar uma conta sem pagamento traz multa e juros de atraso que desfazem o avanço.
  3. Escolha um método. Bola de neve: o extra vai primeiro para o menor saldo. Avalanche: vai primeiro para os maiores juros.
  4. Defina um extra fixo. Um valor que você consiga manter todo mês, mesmo que seja pequeno.
  5. Passe o mínimo adiante. Quando você quita uma dívida, o mínimo dela se soma ao extra e vai para a próxima. Você paga o mesmo por mês, mas cada dívida cai mais rápido.

O extra corta 6 meses e cerca de 3.383 de juros (na bola de neve). Entre os dois métodos, a avalanche economiza 477,27 a mais; a bola de neve quita a primeira dívida no mês 3 e a avalanche também no mês 3 (o cheque especial, que tem os maiores juros).

Qual escolher?

Com juros de cartão e cheque especial tão altos, a avalanche costuma valer a pena. Se você precisa de uma vitória rápida para não desistir, a bola de neve ajuda. A melhor forma de decidir é rodar os seus próprios números.

Teste com as suas dívidas na calculadora grátis para sair das dívidas. Para acompanhar numa planilha, existe o Plano para Sair das Dívidas para Google Sheets e Excel (5 USD).

Como os números foram feitos: juros ao mês aplicados sobre o saldo de cada mês. Os bancos podem somar IOF e tarifas. É um exemplo, não consultoria financeira.
